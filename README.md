# GoPost API

A RESTful API built with Go, Gin, PostgreSQL, JWT authentication, and Docker.

## Features

- User registration and login
- JWT authentication
- Refresh tokens
- Password hashing with bcrypt
- User CRUD operations
- Post CRUD operations
- PostgreSQL database
- Docker & Docker Compose support
- Rate limiting
- CORS middleware
- Layered architecture
  - Handler
  - Service
  - Repository

## Tech Stack

- Go
- Gin
- PostgreSQL
- JWT
- bcrypt
- Docker
- Docker Compose

---

## Running with Docker

### Requirements

You only need:

- Docker
- Docker Compose

You don't need to install Go or PostgreSQL.
